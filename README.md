# 📑 Midad Knowledge Repository

نظام برمجي مصمم لإدارة وتخزين واستعراض الأفكار والرؤى المعرفية (Insights) كبنية تحتية داعمة للمنصة.

---

## 🛠️ التقنيات المستخدمة
* **Python 3.10+**
* **SQLite / Database Engine** (لإدارة وحفظ البيانات محلياً)

## 📂 هيكل ملفات المشروع الحالي
* `engine.py`: المحرك الأساسي ومعالج البيانات.
* `add_insight.py`: واجهة إضافة الرؤى والبيانات الجديدة للمستودع.
* `view_midad.py`: واجهة استعراض وتنسيق البيانات المخزنة.
